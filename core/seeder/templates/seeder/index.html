Generate demo data

New users sign in with the password {{ password }}. They get the role “Seed: business access” and access to all rows. Existing companies are reused. Parents are filled before children; inline rows (lines, options…) are added to every record.

Rows per model
How many records each ticked model gets (1–200). Departments and designations (shared by every company) get this many too; inline rows (1–4 per record) come on top.
New users
Demo people to create (0–50), each a member of one or two companies. 0 keeps the seeded users you already have.
New companies
Extra companies to add (0–10). Existing companies are always used too; one is made when there are none.
Random seed
Any whole number, e.g. 1, 42 or 2026. Leave it empty for different data every time. The same seed on the same starting data gives the same names, amounts and picks again, which helps to reproduce a bug or a demo. Numbers already in the tables (codes, e-mails) keep counting up, so a second run with the same seed is not an exact copy.
Activity
After the rows are made, about 60 % of approvable records are submitted for approval and some steps are decided (this raises notifications), and up to 10 internal mails are sent between seeded users.
